# NutriScan · Primera experiencia

Interfaz responsive enfocada en seleccionar y revisar una fotografía de comida.

- Selección desde galería o cámara.
- Arrastrar y soltar una imagen.
- Vista previa, cambio y eliminación de la foto.
- Validación de tipo y tamaño (máximo 10 MB).
- Sin base de datos ni resultados nutricionales simulados.
- El análisis de IA queda pendiente para una etapa posterior.

Para ejecutar localmente: npm install y npm run dev.
